# Travel-Website
🌐 PHP Website Project

A simple PHP-based website demonstrating basic web development concepts such as page routing, reusable components, and form-based user interaction.

📌 Features

📄 About Page

📘 Booking Page

🧩 Modular PHP structure

⚡ Simple and lightweight implementation

🎓 Suitable for college mini-projects and beginners

🛠️ Technologies Used

Frontend: HTML, CSS

Backend: PHP

Server: Apache (XAMPP / WAMP / LAMP)

📂 Project Structure
/project-root
│
├── about.php        # About page
├── book.php         # Booking page
├── README.md        # Project documentation
🚀 How to Run the Project

Install XAMPP or WAMP

Start Apache Server

Copy project folder to:

htdocs (XAMPP) or www (WAMP)

Open browser and visit:

http://localhost/project-folder-name/
🧪 Sample Use Case

View information on the About page

Submit booking details through the Booking page

Understand PHP page navigation and form handling
